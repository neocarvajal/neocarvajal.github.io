# Erick Carvajal — Portfolio

Blockchain Developer & Web3 Builder de LATAM. Especializado en Solana, Rust, Anchor y Smart Contracts.

## Stack

- **Framework:** Next.js 16 (App Router, Turbopack, static export)
- **Language:** TypeScript
- **Styling:** Tailwind CSS v4, shadcn/ui
- **Animations:** GSAP + ScrollTrigger, Framer Motion
- **Infrastructure:** Helius RPC
- **Deployment:** GitHub Actions → GitHub Pages

## Features

- Video scrub background con timeline animado
- i18n ES/EN con toggle flotante
- Secciones: Cover, About, Experience, Certifications, Projects, Blog, Social
- Modo oscuro/claro

## Desarrollo

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # genera /out para deploy estático
```
